# Hari Arts and Science College – React Website

## Requirements
- Node.js (LTS)
- Visual Studio Code

## Run the website
1. Extract this ZIP file.
2. Open the extracted `hari-college-react` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown in the terminal (usually http://localhost:5173).

## Create a production build

```bash
npm run build
```

The production website files will be created in the `dist` folder.

## Important
Student login, result lookup, and fee payment are front-end demonstrations only. They do not connect to a real student database or payment gateway. Add a secure backend before using them with real student information or payments.
